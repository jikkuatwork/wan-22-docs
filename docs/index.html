About WAN 2.2

WAN 2.2 is an advanced AI video generation model that offers comprehensive cinematic controls including lighting, composition, camera movement, and visual styles. This documentation provides examples of each control type to help you create professional-quality videos.

Key Features:

  • Cinematic Lighting Control: From natural sunlight to artificial studio lighting
  • Professional Shot Types: Close-ups, wide shots, and everything in between
  • Dynamic Camera Movement: Pans, tilts, tracking shots, and more
  • Visual Styles: Animation styles, artistic effects, and visual treatments
  • Motion Control: Precise control over character actions and scene dynamics
